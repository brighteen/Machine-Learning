## 1. 서론

신경망의 성능은 구조(입력 및 은닉 노드 수)와 가중치, 훈련 계수 등 다양한 요소에 의해 좌우됨
최적화된 구조와 가중치를 갖는 신경망은 일반화 성능이 뛰어나지만, 최적의 구조를 찾는 것은 많은 시간과 노력이 필요.
Why? 신경망을 설명할 수 있는 방법이 없음.
```
"신경망의 성능은 구조와 가중치 등 다양한 요소에 영향을 받는데 이 구조를 찾는 것이 매우 힘들다고 합니다. 그럴 수 밖에 없는게 이 신경망을 우리는 설명할 수 있는 방법이 없기 때문에 오로지 설계자의 결험이나 시행착오에 의존할 수 밖에 없습니다."
```
구조 최적화 방법으로는 크게 **구조 증가(constructive) 방법**과 **가지치기(pruning) 방법**이 있음.
```
"기존 구조 최적화 방법에는 크게 구조 증가와 가지치기가 주로 사용되었는데 먼저 구조 증가는 말 그대로 노드를 늘리거나 노드간 연결을 더 해서 좀 더 복잡한 패턴을 학습시키자 이고, 
```
![[구조증가.png]]
```
가지치기는 전에 말했듯이 좀 테스트 데이터를 덜 맞추고 성능을 일반화 시키자는 방법입니다."
```
![[Attached file/유전알고리즘/논문발표/가지치기.png]]

본 논문에서는 신경망의 노드 가지치기를 위한 유전 알고리즘을 제안하며, 입력층과 은닉층이 상호 연관되어 있다는 점에 착안하여 **두 층의 노드를 하나의 염색체로 표현하여 동시에 최적화**하는 방법을 시도함.
특히 유전 알고리즘 연산 과정에서 생성되는 신경망은 부모의 가중치를 상속받아 학습 효율성을 높임.
```
"본 논문에서는 신경망의 구조 증가보다는 가지치기를 얼마나 할 것인가를 유전알고리즘으로 정하고, 입력층과 은닉층을 하나의 염색체로 표현해 동시에 최적화 하는 방법을 시도했고, 추가로 연산 과정에서 생성되는 신경망. 즉 자식 신경망은 부모의 가중치를 상속받아 학습 효율성을 높이는 방법을 제시했습니다."
```

## 2. 관련 연구

신경망 최적화는 일반화 능력이 뛰어난 구조와 가중치를 찾는 작업.
일반화 성능이 좋은 신경망을 찾기 위해, 보통 신경 망의 구조를 여러 가지로 변경하며 성능 실험을 하여 그중 가장 좋은 것을 답으로 취함.
적절한 네트워크 구조를 사전에 알기 어렵고 휴리스틱 방법은 많은 시간이 소요되는 문제가 있어, 이를 해결하기 위해 구조 증가 및 **가지치기(Pruning) 알고리즘**이 사용됨.
```
"신경망을 어떻게 가볍고 효율적으로 만들 수 있을까. 앞에서 말했듯이 신경망을 설명할 수 있는 방법이 없기 때문에 구조에 정답은 없습니다. 다만 좀 더 좋은 성능을 내기 위해 여러 구조를 테스트해보며 경험을 쌓고, 시행착오를 겪는 과정에서 보다 좋은 구조를 발견해 내는 것입니다."
```

신경망 가지치기 방법에는 크게 **민감도 방법**, **정규화/패널티 방법**, **유전 알고리즘 이용 방법**이 있으며, 유전 알고리즘을 이용한 최적화는 다시 **가중치 최적화**, **구조 최적화**, **가중치와 구조 동시 최적화**로 나눌 수 있습니다.
```
"신경망의 가지치기 방법은 민감도 방법, 패널티, 유전알고리즘 방법이 있는데 민감도와 패널티 방법은 매개변수에 성능이 좌우되어 지역 최적해에 쉽게 빠질 수 있는 반면 유전알고리즘은 교차 및 돌연변이 과정을 통해 보다 더 나은 세대로 진화해 전역 최적해에 도달할 수 있고, 이러한 특성 때문에 본 논문에서는 유전알고리즘으로 신경망의 구조와 가중치를 최적화하는 방법을 택했습니다."
```
유전 알고리즘과 신경망 결합 시 중요한 문제는 신경망 구조를 염색체로 어떻게 표현하느냐입니다. **직접 표현(Direct Encoding)** 은 노드나 가중치를 직접 염색체로 표현하는 방식이고, **간접 표현(Indirect Encoding)** 은 값이 만들어지는 규칙을 염색체로 표현하는 방식입니다.
```
"유전알고리즘에서 중요한 것은 염색체를 어떻게 표현하는지, 적합도 함수를 어떻게 정의하는지에 따라서 성능이 결정되는데 이 논문에서는 가지치기를 하냐 안하냐를 이진 리스트로 구현해 가장 효율적인 0과 1의 조합을 찾아내는 알고리즘을 제안했습니다."
```

## 3. NNPGA 알고리즘
![[NNPGA 알고리즘.png]]
### 표현 방식
신경망의 입력층과 은닉층 노드의 제거 여부를 '0'(제거) 또는 '1'(유지)로 표현하여, 전체 염색체는 입력층과 은닉층 노드 수를 합한 길이의 비트열로 구성됩니다.
```
"먼저 노드의 제거 여부를 0과 1로 표현한다고 정의하고 0과 1로 이루어진 임의의 염색체를 생성합니다."
```
![[초기 염색체.png]]
### 초기 해집단
모든 비트를 1로 시작한 후 원하는 가지치기 비율에 따라 임의의 위치에서 특정 개수의 비트를 0으로 변경합니다.
```
"현재는 입력층이 4개, 은닉층이 4개로 이루어진 구조에서 원하는 가치지기 비율에 따라 노드를 제거한 후에 그에 맞게 염색체를 0과 1로 표현합니다."
```

### 적합도 평가 및 선택
검증 집합에 대한 RMSE(Root Mean Square Error) 값을 기반으로 적합도를 평가하며, 선택 연산에는 순위 기반 룰렛 휠 방법을 사용합니다.

$$
p_i = \frac{1}{1 + e}, \quad i = 1, \ldots, N
$$
$$
e = \frac{1}{n} \sum_{i=1}^{n} \sqrt{ \frac{1}{m} \sum_{j=1}^{m} (y_j^i - t_j^i)^2 }
$$

```
"만들어진 염색체에 대해 적합도 평가를 하는데 현재는 RMSE(Root Mean Square Error)값에 1을 더한 값의 역수를 적합도 함수로 나타냈습니다. 이것은 RMSE값이 작을 수록 모델의 오차가 작을 수록 적합도 값은 커지기에 다음 세대에 RMSE값이 작은 즉 오차가 적은 염색체를 넘기도록 유도하는 메커니즘입니다. 여기서 저희가 흔히 신경망에서 사용하는 MSE를 사용하지 않고 루트를 씌운 이유는 현재 RMSE가 학습에 쓰이는게 아니라 오로지 오류값을 해석하는데에만 쓰였기에 실제 오차의 크기를 보려고 루트를 사용한 것 같습니다. 선택 연산자는 순위 기반 룰렛 휠 방법로 적합도가 높은 유전자가 유리하게 선택되도록 설정했습니다."
```
### 교차와 돌연변이
선택된 부모 염색체는 교차와 돌연변이 연산을 통해 자식 해를 생성합니다. 교차와 돌연변이 후 목표 가지치기 비율이 유지되도록 비트를 조정합니다.
```
"교차는 3점 교차, 돌연변이는 각 비트에 대해 임의 수를 생성하고 그 수와 미리 설정한 임계값과 비교해 0은 1로, 1은 0으로 바꾸는 방법을 택했습니다.
```
### 가중치 상속과 신경망 재훈련
자식 염색체의 가중치는 부모로부터 상속받으며, 이는 다음 네 가지 경우로 나뉩니다:
1. 부모 중 하나에만 가중치가 존재하면 해당 가중치 상속
2. 부모 모두 가중치가 존재하면 평균 값 상속
3. 부모 모두 가중치가 없으면 임의 값 상속
```
"앞서 선택, 교차, 돌연변이를 통해 신경망의 구조를 물려받았으면 이제 가중치를 상속받아야 합니다. 최대한 부모에게 가중치를 상속받기 위해 다음과 같이 앵간하면 부모의 가중치를 물려받자는 매커니즘을 구현했습니다. 부모에게 가중치를 상속받는 것은 이미 적합도 계산을 통해 어느정도 검증된 신경망의 가중치이기에 의미있는 시작과 더불어 빠르고 안정적인 학습이 가능하기 때문에 충분히 근거있는 상속과정이라고 생각합니다."
```
![[가중치 상속.png]]
```
자식 신경망의 가중치 계산을 해보면 일단 부모에게 받은 구조에 맞게 가중치를 설정하면 됩니다. 첫번째 간선(w_11)에는 0.2와 0.3의 평균 0.25를 건내주고, 두번째 간선(w_13)은 P_2에만 존재하기에 그대로 가져오고 3번째 간선(w_41), 4번째 간선(w_42)은 부모 모두 가중치가 없기에 임의 값을 주었습니다.
```
이 가중치 상속 과정은 오류 역전파의 지역 최적해 문제 극복에 도움이 됩니다.

## 4. 실험 결과 및 토론
