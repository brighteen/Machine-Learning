# **구현 계획 제시하기**

## 1. 해법 모형화

### 1.1 개체(Chromosome) 표현

* **유전자 배열**: 길이 = 전체 수업 과목 수
* **각 유전자(Gene)**:

  * **시간 슬롯 인덱스** (예: 1–14×요일 수 + 금요일 연강용 슬롯)
  * **강의실 인덱스** (1학년→423, 2→424, 3→514, 4→425)
* 예를 들어, `gene[i] = (slot_i, room_i)` 형태로 표현

### 1.2 초기 개체군 생성

* **무작위 배정**: 모든 과목에 대해 가능한 슬롯 중에서 랜덤 선택
* 단, 절대 불가 슬롯(점심 7–8교시, 고정 불가 시간대)은 제외


## 2. 적합도 함수(Fitness)

### 2.1 하드 제약 위반 패널티

* 학생·교수·강의실 충돌 발생 시 큰 페널티
* 점심·저녁시간, 1.5h 짝꿍 규칙 위반 시 큰 페널티
* 3h 연강 과목이 금요일 외에 배치되면 큰 페널티

### 2.2 소프트 제약 페널티

* 교수별 수업일 분산이 4일 미만인 경우 일정 비율의 페널티
* 3h 연강 과목이 월\~목에 너무 집중되면 소폭 페널티

### 2.3 종합 점수
```
fitness = − ( w_hard × ∑HardViolations + w_soft × ∑SoftViolations )
```

* 상수 `w_hard ≫ w_soft` 로 설정


## 3. 유전 연산자

### 3.1 선택(Selection)

* **토너먼트 선택** (k=3\~5) 또는 **룰렛 휠**

### 3.2 교차(Crossover)

* **부분 맵 교차(PMX)**: 두 부모의 유전자 블록(예: 특정 학년 블록) 교환
* 또는 **일점 교차**: 배열 인덱스 한 지점 자르고 교환

### 3.3 돌연변이(Mutation)

* **슬롯 재배정**: 일정 확률로 한 과목의 `slot`을 동일 학년 가능 슬롯 중 랜덤 재선택
* **강의실 변경**: (학년별 강의실이 고정되어 있다면 불필요)


## 4. 알고리즘 흐름

1. **초기화**: 인구 수 N 생성
2. **평가**: 각 개체의 fitness 계산
3. **반복 (t = 1…T)**

   1. 선택으로 부모 풀 구성
   2. 교차·돌연변이로 자식 생성
   3. 자식 평가
   4. **엘리트 보존**: 상위 E개체 차세대로 자동 승계
   5. 세대 교체
4. **종료 조건**: 최대 세대 도달 또는 만족할 만한 fitness 획득 시 멈춤
5. **결과**: 최적 개체를 해석해 시간표 완성


## 5. 하이퍼파라미터 예시

* 개체 수 N = 200
* 세대 수 T = 500
* 교차 확률 Pc = 0.8
* 돌연변이 확률 Pm = 0.1
* 엘리트 크기 E = 5
