# 신경망의 노드 가지치기를 위한 유전 알고리즘 (NNPGA)

본 프로젝트는 신경망 구조 최적화를 위한 노드 가지치기 방법론을 구현한 것입니다. 유전 알고리즘을 사용하여 신경망의 입력층과 은닉층 노드를 동시에 최적화합니다.

## 개요

신경망의 구조를 최적화하는 방법은 크게 두 가지가 있습니다:
1. **노드 가지치기(Pruning)**: 큰 네트워크에서 불필요한 노드를 제거하는 방법
2. **구조 증가(Constructive)**: 작은 네트워크에서 점진적으로 노드를 추가하는 방법

이 프로젝트는 노드 가지치기 방법을 사용하며, 최적의 가지치기 구조를 찾기 위해 유전 알고리즘을 적용합니다. 기존 연구와의 차별점은 입력층과 은닉층의 노드를 동시에 최적화한다는 점입니다. 4개의 표준 UCI Machine Learning Repository 데이터셋(Iris, Wine, Digits, Breast Cancer)에 대한 실험을 통해 방법론의 효과를 검증하였습니다.

## 주요 특징

- 입력층과 은닉층 노드를 하나의 염색체로 표현하여 동시 최적화
- 부모 신경망의 가중치를 자식 신경망에 상속하는 메커니즘
- 다양한 가지치기 비율에 따른 성능 비교 지원
- 표준 UCI Machine Learning Repository 데이터셋 지원 (Iris, Wine, Digits, Breast Cancer)
- 가지치기 비율에 따른 정확도 시각화
- 10-겹 교차검증(10-fold cross validation)을 통한 성능 평가
- 세 가지 가지치기 방법(입력+은닉층, 입력층만, 은닉층만) 비교

## 파일 구조

- `main.py`: 메인 실행 파일
- `neural_network.py`: 신경망 모델 구현
- `genetic_algorithm.py`: 유전 알고리즘 및 염색체 구현
- `data_processor.py`: 데이터 전처리 및 K-겹 교차 검증
- `evaluator.py`: 성능 평가 및 시각화
- `run_all_datasets.py`: 모든 데이터셋에 대한 일괄 실행 스크립트
- `results/`: 실험 결과 저장 디렉토리

## 사용 방법

기본 설정으로 실행:

```bash
python main.py
```

사용자 정의 설정으로 실행:

```bash
python main.py --dataset iris --prune_rate 0.1 --pop_size 20 --generations 150 --epochs 100 --k_folds 10
```

모든 데이터셋에 대해 일괄 실행:

```bash
python run_all_datasets.py
```

### 매개변수 설명

- `--dataset`: 사용할 데이터셋 (iris, wine, digits, breast_cancer)
- `--prune_rate`: 가지치기 비율 (0~1 사이)
- `--pop_size`: 유전 알고리즘 인구 크기
- `--generations`: 유전 알고리즘 세대 수
- `--epochs`: 신경망 학습 에포크 수
- `--crossover_rate`: 교차 확률
- `--mutation_rate`: 돌연변이 확률
- `--selection_pressure`: 선택 압력
- `--k_folds`: K-겹 교차검증의 폴드 수
- `--random_state`: 랜덤 시드
- `--verbose`: 상세 출력 모드
- `--output_dir`: 결과 저장 디렉토리

## 알고리즘 설명

### 염색체 표현

각 염색체는 입력층과 은닉층 노드의 제거 여부를 나타내는 이진 스트링입니다. 1은 노드 유지, 0은 노드 제거를 의미합니다.

예를 들어, 입력층 4개 노드와 은닉층 3개 노드를 가진 신경망의 염색체는 다음과 같을 수 있습니다:
```
[1, 0, 1, 1, 0, 1, 0]
```
이는 두 번째 입력 노드, 첫 번째와 세 번째 은닉 노드가 제거됨을 의미합니다.

### 유전 연산

1. **선택**: 순위 기반 룰렛 휠 선택
2. **교차**: 3점 교차를 통해 두 부모 염색체로부터 자식 염색체 생성
3. **돌연변이**: 유전자별로 지정된 확률로 값 반전 (0→1, 1→0)
4. **가중치 상속**: 네 가지 경우에 따라 가중치 상속
   - 부모1만 가중치 존재: 부모1에서 상속
   - 부모2만 가중치 존재: 부모2에서 상속
   - 두 부모 모두 가중치 존재: 두 부모 가중치의 평균 상속
   - 두 부모 모두 가중치 없음: [-1, 1] 사이 임의 값 할당

## 실험 결과

### 실험 설정
- 10-겹 교차검증 사용
- 인구 크기: 20
- 세대 수: 150
- 에포크 수: 100
- 교차 확률: 1.0
- 돌연변이 확률: 0.01
- 선택 압력: 0.25

### 데이터셋별 결과

#### 1. Iris 데이터셋
- 신경망 구조: 4-12-3
- 최적 가지치기 비율 및 정확도:
  - 입력+은닉층: 0.15 (91.33%)
  - 입력층: 0.04 (72.00%)
  - 은닉층: 0.04 (67.33%)

#### 2. Wine 데이터셋
- 신경망 구조: 13-12-3
- 최적 가지치기 비율 및 정확도:
  - 입력+은닉층: 0.08 (98.89%)
  - 입력층: 0.25 (68.86%)
  - 은닉층: 0.30 (66.24%)

#### 3. Digits 데이터셋
- 신경망 구조: 64-40-10
- 최적 가지치기 비율 및 정확도:
  - 입력+은닉층: 0.50 (11.63%)
  - 입력층: 0.30 (10.80%)
  - 은닉층: 0.50 (11.02%)

#### 4. Breast Cancer 데이터셋
- 신경망 구조: 30-8-2
- 최적 가지치기 비율 및 정확도:
  - 입력+은닉층: 0.10 (97.72%)
  - 입력층: 0.45 (75.55%)
  - 은닉층: 0.04 (74.50%)

### 종합 분석

1. **가지치기 방법 비교**
   - 입력+은닉층 동시 가지치기가 일관되게 가장 높은 성능을 보였습니다 (평균 정확도 74.89%).
   - 입력층 단독 가지치기와 은닉층 단독 가지치기는 비슷한 성능을 보였습니다 (평균 정확도 각각 56.80%, 54.77%).

2. **최적 가지치기 비율**
   - 입력+은닉층: 평균 0.21 (0.08~0.50)
   - 입력층: 평균 0.26 (0.04~0.45)
   - 은닉층: 평균 0.22 (0.04~0.50)
   - 일반적으로 0.1~0.3 사이의 가지치기 비율이 많은 데이터셋에서 효과적이었습니다.

3. **데이터셋 복잡성에 따른 성능**
   - 간단한 데이터셋(Iris, Wine, Breast Cancer)에서는 높은 정확도를 달성했습니다.
   - 복잡한 데이터셋(Digits)에서는 성능이 저조했습니다. 이는 복잡한 문제에 대해 더 큰 네트워크와 더 많은 훈련이 필요함을 시사합니다.

## 결론 및 향후 연구 방향

신경망 노드 가지치기를 위한 유전 알고리즘은 적절한 파라미터 설정과 데이터셋 특성에 맞는 조정을 통해 효과적으로 작동할 수 있습니다. 특히 입력층과 은닉층을 동시에 가지치기하는 방법이 일관되게 좋은 성능을 보이는 것으로 확인되었습니다.

향후 연구 방향:
1. **네트워크 구조 최적화**: 데이터셋의 복잡성에 따라 은닉층의 크기를 조정
2. **훈련 파라미터 조정**: 에포크 수, 학습률 등을 데이터셋에 맞게 조정
3. **유전 알고리즘 개선**: 선택, 교차, 돌연변이 연산자를 개선하여 더 효과적인 탐색
4. **추가 데이터셋 실험**: 다양한 복잡성을 가진 더 많은 데이터셋에서 실험
5. **다른 가지치기 방법과의 비교**: 다른 가지치기 알고리즘(예: 가중치 기반 가지치기)과 비교
