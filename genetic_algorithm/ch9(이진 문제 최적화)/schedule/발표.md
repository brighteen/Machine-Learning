#### **Slide 2. 문제 정의 및 목표**

- **시각화 제안:**

#### **Slide 3. 유전 알고리즘 핵심 개념**
- **제목:** 2. 유전 알고리즘 기본 원리
- **내용 요약:**  
  - GA는 해를 진화시켜 최적의 결과를 찾음
  - 핵심 구성: 해(x)와 적합도(f(x))
- **시각화:**  
  - `x → f(x)` 흐름도  
  - 선택 → 교차 → 돌연변이 → 평가 반복 다이어그램

---

#### **Slide 4. 해의 표현 (x)**
- **제목:** 3.1 유전자의 구조: 해의 표현
- **내용 요약:**  
  - 해는 0/1 비트열로 표현됨  
  - 구조: 직원 수 × 날짜 수 × 3(근무조)
  - 예: 3명, 2일 → 3×2×3 = 18비트
- **시각화:**  
  - gene list 예시 + `create_schedule()` → DataFrame 전환 그림

---

#### **Slide 5. 적합도 함수 (f(x))**
- **제목:** 3.2 적합도 함수: 제약 위반 패널티 기반
- **내용 요약:**  
  - `shift_deviations`: 최소/최대 인원 초과 여부
  - `shift_relax`: 연속 근무 후 휴식 위반
  - `f(x) = - (편차 + 휴식위반 × 가중치)`
- **시각화:**  
  - 위반 건수 시각화 예시, penalty 계산 방식 flowchart

#### **Slide 6. GA 연산 구성**
- **제목:** 4. 유전 알고리즘 구조
- **내용 요약:**  
  - 초기화 → 선택 → 교차 → 돌연변이 → 평가
  - 선택: 랭크 기반 + 엘리트
  - 교차: N-포인트 교차
  - 돌연변이: 비트 플립
- **시각화:**  
  - 전체 프로세스 흐름도  
  - crossover 시각화 그림 (`crossover n-point.png` 사용)
