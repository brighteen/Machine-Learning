# 캐싱(Caching) 최적화 기법

이 폴더는 유전 알고리즘의 성능을 향상시키기 위한 캐싱(caching) 기법을 구현한 코드를 포함합니다.

## 설명

유전 알고리즘에서는 같은 유전자 구성을 가진 개체가 여러 번 생성되어 평가될 수 있습니다. 이런 중복 계산을 피하기 위해 캐싱 기법을 사용합니다.

### 주요 기능

- 개체의 유전자 구성을 해시 키로 사용하여 적합도 값을 캐시에 저장
- 같은 유전자 구성이 다시 나타날 때 캐시된 적합도 값 재사용
- 캐시 히트 카운터로 성능 향상 측정 가능

### 핵심 파일

- `individual.py`: 캐싱 메커니즘이 구현된 Individual 클래스
- `ga_with_caching.py`: 캐싱 기능을 활용한 유전 알고리즘 구현
- `schedule_analyzer.py`: 스케줄 품질 평가 함수들
- `toolbox.py`: 유전 알고리즘에 필요한 다양한 연산자들

## 활용

이 구현은 특히 적합도 계산이 복잡하거나 시간이 많이 소요되는 문제에서 큰 성능 향상을 가져옵니다. 예제에서는 직원 스케줄링 문제를 통해 그 효율성을 보여줍니다.
