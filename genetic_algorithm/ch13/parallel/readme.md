# 병렬 처리(Parallel Processing) 최적화 기법

이 폴더는 유전 알고리즘의 성능을 향상시키기 위한 병렬 처리(parallel processing) 기법을 구현한 코드를 포함합니다.

## 설명

유전 알고리즘의 교차(crossover)와 돌연변이(mutation) 연산은 서로 독립적으로 수행될 수 있어 병렬 처리에 적합합니다. 이 구현은 Python의 멀티프로세싱 기능을 활용하여 연산을 병렬화합니다.

### 주요 기능

- 멀티프로세싱 풀을 사용한 교차 연산 병렬 처리
- 멀티프로세싱 풀을 사용한 돌연변이 연산 병렬 처리
- 레이더 배치 문제에 적용한 예시 구현

### 핵심 파일

- `individual.py`: 레이더 배치 문제를 위한 개체 클래스
- `landscape.py`: 지형과 레이더 커버리지를 모델링하는 클래스 및 시각화 함수
- `toolbox.py`: 병렬 처리가 구현된 유전 알고리즘 연산자들
- `ga_parallel.py`: 병렬 처리 유전 알고리즘의 메인 실행 파일

## 활용

이 병렬 처리 기법은 특히 큰 인구 크기와 복잡한 연산이 필요한 문제에서 유전 알고리즘의 실행 시간을 단축시킵니다. 예제에서는 레이더 배치 문제를 통해 그 효율성을 보여줍니다.
