# 거친 인코딩(Coarse Encoding) 최적화 기법

이 폴더는 유전 알고리즘의 성능을 향상시키기 위한 거친 인코딩(coarse encoding) 기법을 구현한 코드를 포함합니다.

## 설명

연속적인 값을 가진 유전자는 미세한 차이로 인해 동일한 성능을 가진 개체들이 서로 다른 것으로 인식될 수 있습니다. 거친 인코딩은 이러한 미세한 차이를 반올림하여 유사한 개체들을 동일하게 처리합니다.

### 주요 기능

- 실수 유전자 값을 반올림하여 거친(coarse) 표현으로 변환
- 유사한 유전자 구성을 가진 개체들을 동일하게 취급하여 탐색 공간 축소
- 캐싱과 결합하여 계산 효율성 향상

### 핵심 파일

- `individual.py`: 거친 인코딩이 구현된 Individual 클래스

## 활용

이 기법은 연속적인 값을 가진 문제에서 유전 알고리즘의 탐색 효율성을 높이는 데 유용합니다. 유사한 솔루션을 중복으로 평가하지 않고 더 넓은 탐색 범위에 집중할 수 있게 해줍니다.
